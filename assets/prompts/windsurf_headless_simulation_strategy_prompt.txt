Goal:
Add an option to run a simulation without displaying the live 2D/3D simulation.
Instead, the simulation should run in the backend/headless flow and only return/display the final statistics result.

Current situation:
- The system has 2D and 3D simulation visualization.
- The simulation is lifelong by default.
- The user can configure simulation settings.
- The system already tracks statistics such as:
  - Exit: # Exited, Avg Steps

- We are also planning/considering expanded statistics such as:
  - Average total trip duration
  - Longest trip duration
  - Shortest trip duration
  - Average planner runtime
  - CPU usage
  - Memory usage
- The system supports at least two planner options:
  - LaCAM0
  - Priority Planner

Requested feature:
Add a Headless Mode option in the simulation configuration UI.

My UI idea:
- Add a checkbox or toggle/slide button:
  - “Activate Headless Mode”
  - or “Headless Simulation”
- When Headless Mode is enabled:
  - The simulation should NOT display live movement.
  - The user should only receive the final statistics after the simulation finishes.
  - A maximum step count MUST be configured by the user.
  - This is required because the simulation is lifelong by default.

Main rule:
If Headless Mode is selected, the user must configure a maximum timestep / max steps value.
The system should prevent starting a headless simulation without max steps.
